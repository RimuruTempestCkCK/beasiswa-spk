Catatan tentang dasar dokumen
Dokumen ini mengacu pada proposal penelitian yang disediakan, terutama penggunaan enam variabel (IPK, penghasilan orang tua, jumlah tanggungan keluarga, prestasi akademik, prestasi nonakademik, dan kehadiran), K-Means dengan DBI, serta Backpropagation yang menggunakan label hasil clustering. Detail implementasi web, kebutuhan nonfungsional, struktur direktori, rancangan tabel, dan use case merupakan rancangan teknis yang diusulkan untuk mewujudkan penelitian menjadi aplikasi.
Penting: karena target Backpropagation adalah label K-Means, metrik klasifikasi mengukur seberapa baik jaringan meniru label cluster. Itu tidak otomatis membuktikan kelayakan beasiswa yang sebenarnya. Interpretasi cluster menjadi kategori seperti prioritas tinggi/sedang/rendah harus disepakati dan divalidasi oleh pihak kampus. Jika kelak tersedia keputusan resmi historis, hasil resmi perlu dianalisis sebagai sumber validasi terpisah.

1. Ringkasan Eksekutif
Aplikasi ini merupakan aplikasi web untuk membantu pengelolaan dataset mahasiswa dan menjalankan analisis data guna mengelompokkan karakteristik pendaftar beasiswa. Sistem menggunakan K-Means Clustering untuk membentuk cluster dan DBI untuk membandingkan kualitas cluster. Label cluster selanjutnya digunakan sebagai target pelatihan Backpropagation sehingga model dapat mengklasifikasikan data baru ke dalam pola cluster yang telah dipelajari.
Aplikasi tidak boleh menyebut hasil model sebagai keputusan resmi penerima beasiswa. Hasil harus ditampilkan sebagai cluster atau rekomendasi berbasis pola data, dengan penjelasan bahwa keputusan akhir tetap memerlukan verifikasi kriteria beasiswa dan otorisasi petugas.
2. BRD — Kebutuhan Bisnis
2.1 Latar belakang
Proses analisis calon penerima beasiswa membutuhkan pengolahan data akademik dan sosial-ekonomi yang terstruktur. Aplikasi ini dirancang untuk mengurangi pengolahan manual, menyimpan jejak eksperimen, menampilkan hasil clustering dan evaluasi model, serta membantu analisis calon mahasiswa baru.
2.2 Tujuan bisnis
Menyediakan satu tempat untuk mengimpor, memvalidasi, dan mengelola dataset mahasiswa.
Membuat proses preprocessing dapat ditinjau dan diulang secara terkontrol.
Menyediakan eksperimen K-Means dengan beberapa nilai K dan perbandingan nilai DBI.
Melatih model Backpropagation dari label cluster yang dihasilkan K-Means.
Menyajikan evaluasi model dan prediksi secara transparan, dengan keterbatasan metode yang jelas.
Menyediakan laporan dan jejak audit atas dataset, konfigurasi, versi model, serta hasil prediksi.

6.1 Metadata dan identitas
Gunakan student_code sebagai identifier bisnis jika tersedia dan diizinkan. Nama mahasiswa bersifat opsional untuk proses analitik; dataset penelitian dapat menggunakan kode pseudonim. Jangan memakai NIM atau nama sebagai input algoritma. Tetapkan kebijakan akses, retensi, dan penghapusan data.
6.2 Kamus data prestasi — belum final
Proposal menetapkan prestasi akademik dan nonakademik sebagai variabel, tetapi skala numerik operasional belum ditetapkan dalam rancangan ini. Sebelum training, kampus/peneliti harus menyepakati aturan, misalnya berdasarkan tingkat capaian, jenis prestasi, atau skor berbobot. Aturan tersebut harus terdokumentasi dan digunakan konsisten pada dataset pelatihan serta input prediksi.
6.3 Dataset belum tersedia
Prioritas pertama: meminta data historis pendaftar beasiswa yang telah diizinkan untuk penelitian.
Jika data asli belum tersedia, gunakan dataset sintetis untuk membangun UI, validasi, dan pipeline teknis.
Dataset sintetis harus ditandai jelas dan tidak boleh dipakai untuk menyimpulkan performa nyata di kampus.
Sebelum model dipakai, cek jumlah baris, distribusi variabel, nilai kosong, outlier, dan variasi setiap fitur.

7.2 K-Means Clustering
Pilih enam fitur yang sudah divalidasi dan dinormalisasi.
Tentukan daftar kandidat jumlah cluster K berdasarkan ukuran dan karakteristik dataset; daftar K tidak ditetapkan permanen dalam dokumen ini.
Jalankan K-Means untuk tiap kandidat dengan seed yang dicatat agar eksperimen dapat diulang.
Simpan centroid, parameter, label tiap record, dan metrik DBI.
Bandingkan DBI pada kandidat yang valid. Nilai DBI lebih rendah menunjukkan pemisahan cluster yang relatif lebih baik dalam konteks metrik tersebut.
Pilih eksperimen berdasarkan DBI dan pemeriksaan substantif cluster; DBI saja tidak membuktikan label cluster setara dengan kelayakan beasiswa.
Analisis profil cluster untuk membantu memberi interpretasi. Jangan memberi nama 'layak/tidak layak' secara otomatis tanpa validasi domain.
7.3 Backpropagation
Input X: enam fitur yang sama dengan proses clustering, menggunakan transformasi yang sama.
Target y: cluster_label dari eksperimen K-Means yang dipilih.
Pisahkan data menjadi data latih dan data uji. Pemisahan dilakukan dengan prosedur yang terdokumentasi; bila memungkinkan pertahankan proporsi kelas.
Latih jaringan saraf dengan konfigurasi yang dicatat: jumlah hidden layer/neuron, learning rate, epoch, batch size, seed, dan kriteria penghentian.
Gunakan data uji yang tidak dipakai untuk melatih model maupun memilih konfigurasi final.
Simpan artefak model dan objek preprocessing/scaler sebagai satu versi yang kompatibel.
Evaluasi hasil prediksi terhadap label cluster pada data uji.
7.4 Evaluasi
Metrik
Makna
Catatan interpretasi
DBI
Membandingkan kekompakan cluster dan pemisahan antarkelompok.
Dipakai untuk membandingkan kandidat K; lebih rendah relatif lebih baik.
Confusion matrix
Menampilkan prediksi versus label cluster acuan.
Nama kelas adalah cluster, bukan label resmi beasiswa.
Accuracy
Proporsi prediksi label cluster yang benar.
Dapat menyesatkan bila distribusi kelas tidak seimbang.
Precision
Ketepatan prediksi pada setiap kelas.
Laporkan per kelas dan/atau macro average.
Recall
Kemampuan menemukan record pada setiap kelas acuan.
Laporkan per kelas dan/atau macro average.
F1-score
Rata-rata harmonik precision dan recall.
Jelaskan metode averaging yang digunakan.
Hindari data leakage: normalisasi harus di-fit pada data latih, lalu diterapkan ke data uji; jangan memilih model final berdasarkan performa pada data uji. Karena label berasal dari K-Means, metrik tersebut mengukur kemampuan meniru cluster, bukan akurasi terhadap keputusan resmi kampus.
7.5 Pseudocode alur algoritma
INPUT: dataset mahasiswa dengan enam fitur
 
1. Validasi skema dan rentang data
2. Bersihkan data sesuai aturan terdokumentasi
3. Pisahkan data/record untuk proses eksperimen sesuai rancangan penelitian
4. Fit transformasi preprocessing pada data yang sesuai
5. FOR setiap kandidat K:
       jalankan K-Means dengan seed tercatat
       hitung DBI
       simpan konfigurasi, centroid, label, dan DBI
6. Pilih kandidat berdasarkan DBI dan tinjauan profil cluster
7. Bentuk target y = label cluster dari eksperimen terpilih
8. Bagi data untuk training dan testing dengan prosedur yang terdokumentasi
9. Latih Backpropagation menggunakan X dan y pada data latih
10. Evaluasi prediksi data uji terhadap y uji
11. Simpan model, preprocessing, konfigurasi, dan metrik sebagai versi
12. Untuk input baru:
       validasi input
       transformasikan menggunakan preprocessing versi model
       prediksi cluster menggunakan model versi terpilih
       tampilkan hasil dengan disclaimer interpretasi

10.3 SQL DDL inti (rancangan)
CREATE DATABASE IF NOT EXISTS beasiswa_spk
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE beasiswa_spk;
 
CREATE TABLE users (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(120) NOT NULL,
  email VARCHAR(190) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  role ENUM('admin','operator','reviewer') NOT NULL DEFAULT 'operator',
  is_active BOOLEAN NOT NULL DEFAULT TRUE,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;
 
CREATE TABLE dataset_batches (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  batch_name VARCHAR(150) NOT NULL,
  source_filename VARCHAR(255),
  source_type ENUM('excel','csv','manual','synthetic') NOT NULL DEFAULT 'csv',
  dataset_description TEXT,
  total_rows INT UNSIGNED NOT NULL DEFAULT 0,
  status ENUM('draft','imported','validated','rejected') NOT NULL DEFAULT 'draft',
  created_by BIGINT UNSIGNED NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT fk_batch_user FOREIGN KEY (created_by)
    REFERENCES users(id) ON DELETE SET NULL
) ENGINE=InnoDB;
 
CREATE TABLE student_records (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  dataset_batch_id BIGINT UNSIGNED NOT NULL,
  student_code VARCHAR(60) NULL,
  student_name VARCHAR(150) NULL,
  ipk DECIMAL(4,2) NULL,
  parent_income DECIMAL(15,2) NULL,
  family_dependents SMALLINT UNSIGNED NULL,
  academic_achievement_score DECIMAL(8,3) NULL,
  nonacademic_achievement_score DECIMAL(8,3) NULL,
  attendance_percentage DECIMAL(5,2) NULL,
  data_status ENUM('raw','validated','invalid') NOT NULL DEFAULT 'raw',
  validation_notes TEXT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT fk_record_batch FOREIGN KEY (dataset_batch_id)
    REFERENCES dataset_batches(id) ON DELETE CASCADE,
  INDEX idx_record_batch (dataset_batch_id),
  INDEX idx_record_code (student_code)
) ENGINE=InnoDB;
 
CREATE TABLE preprocessing_runs (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  dataset_batch_id BIGINT UNSIGNED NOT NULL,
  method_version VARCHAR(50) NOT NULL,
  config JSON NULL,
  status ENUM('queued','running','completed','failed') NOT NULL DEFAULT 'queued',
  input_rows INT UNSIGNED NOT NULL DEFAULT 0,
  output_rows INT UNSIGNED NOT NULL DEFAULT 0,
  artifact_path VARCHAR(500) NULL,
  error_message TEXT NULL,
  created_by BIGINT UNSIGNED NULL,
  started_at DATETIME NULL,
  completed_at DATETIME NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (dataset_batch_id) REFERENCES dataset_batches(id),
  FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL
) ENGINE=InnoDB;
 
CREATE TABLE clustering_runs (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  preprocessing_run_id BIGINT UNSIGNED NOT NULL,
  algorithm VARCHAR(50) NOT NULL DEFAULT 'KMeans',
  k_value INT UNSIGNED NOT NULL,
  dbi_score DECIMAL(12,8) NULL,
  random_seed INT NULL,
  config JSON NULL,
  status ENUM('queued','running','completed','failed') NOT NULL DEFAULT 'queued',
  is_selected BOOLEAN NOT NULL DEFAULT FALSE,
  artifact_path VARCHAR(500) NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (preprocessing_run_id) REFERENCES preprocessing_runs(id),
  INDEX idx_cluster_preprocess (preprocessing_run_id)
) ENGINE=InnoDB;
 
CREATE TABLE cluster_assignments (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  clustering_run_id BIGINT UNSIGNED NOT NULL,
  student_record_id BIGINT UNSIGNED NOT NULL,
  cluster_label INT NOT NULL,
  distance_to_centroid DECIMAL(14,8) NULL,
  FOREIGN KEY (clustering_run_id) REFERENCES clustering_runs(id) ON DELETE CASCADE,
  FOREIGN KEY (student_record_id) REFERENCES student_records(id) ON DELETE CASCADE,
  UNIQUE KEY uq_cluster_record (clustering_run_id, student_record_id)
) ENGINE=InnoDB;
 
CREATE TABLE model_versions (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  model_name VARCHAR(150) NOT NULL,
  model_version VARCHAR(50) NOT NULL,
  target_clustering_run_id BIGINT UNSIGNED NOT NULL,
  algorithm VARCHAR(50) NOT NULL DEFAULT 'Backpropagation',
  training_config JSON NULL,
  metrics JSON NULL,
  artifact_path VARCHAR(500) NULL,
  status ENUM('training','ready','failed','archived') NOT NULL DEFAULT 'training',
  created_by BIGINT UNSIGNED NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (target_clustering_run_id) REFERENCES clustering_runs(id),
  FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL,
  UNIQUE KEY uq_model_version (model_name, model_version)
) ENGINE=InnoDB;
 
CREATE TABLE predictions (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  model_version_id BIGINT UNSIGNED NOT NULL,
  ipk DECIMAL(4,2) NOT NULL,
  parent_income DECIMAL(15,2) NOT NULL,
  family_dependents SMALLINT UNSIGNED NOT NULL,
  academic_achievement_score DECIMAL(8,3) NOT NULL,
  nonacademic_achievement_score DECIMAL(8,3) NOT NULL,
  attendance_percentage DECIMAL(5,2) NOT NULL,
  predicted_cluster INT NOT NULL,
  confidence_score DECIMAL(8,7) NULL,
  notes TEXT NULL,
  created_by BIGINT UNSIGNED NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (model_version_id) REFERENCES model_versions(id),
  FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL,
  INDEX idx_prediction_created (created_at)
) ENGINE=InnoDB;
 
CREATE TABLE audit_logs (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT UNSIGNED NULL,
  action VARCHAR(100) NOT NULL,
  entity_type VARCHAR(100) NOT NULL,
  entity_id VARCHAR(100) NULL,
  details_json JSON NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL,
  INDEX idx_audit_created (created_at),
  INDEX idx_audit_entity (entity_type, entity_id)
) ENGINE=InnoDB;
DDL ini merupakan rancangan awal yang perlu diuji melalui migration dan disesuaikan dengan versi MySQL yang digunakan. Nilai kategori prestasi dan kebijakan data null perlu difinalisasi sebelum produksi. Jika data preprocessing ingin disimpan per record dalam bentuk tabular, tambahkan tabel khusus preprocessed_records yang berelasi ke preprocessing_runs dan student_records; artefak scaler tetap harus disimpan bersama versi model.

12. Kebutuhan Nonfungsional dan Keamanan
Kategori
Persyaratan
Keamanan
Password menggunakan hash yang kuat; gunakan HTTPS di deployment; rahasia berada di environment variables.
Otorisasi
Role admin/operator/reviewer membatasi operasi sesuai kebutuhan.
Privasi
Minimalkan data identitas; gunakan pseudonim untuk analisis; batasi akses dataset.
Audit
Catat impor, perubahan data, run algoritma, training, pergantian model aktif, dan ekspor.
Keandalan
Status job persisten; kegagalan dicatat; job dapat ditinjau dan dijalankan ulang.
Reproducibility
Simpan seed, versi library, konfigurasi, preprocessing artifact, data batch, dan versi kode bila memungkinkan.
Kinerja
Paginasi server-side; proses ML berjalan di job worker; batas ukuran upload dan timeout terencana.
Maintainability
Pemisahan route, schema, service, repository, dan modul ML; gunakan migration database.
Backup
Backup database dan direktori artefak secara teratur; uji pemulihan.
Observability
Logging terstruktur tanpa mencatat password atau data pribadi yang tidak perlu.
13. Kriteria Penerimaan
Pengguna yang belum login tidak dapat mengakses halaman dan endpoint yang dilindungi.
Impor dataset menampilkan preview, jumlah baris valid/tidak valid, dan alasan validasi.
Data mentah tetap tersedia setelah preprocessing.
Eksperimen K-Means menyimpan nilai K, seed, DBI, label record, dan status.
Sistem dapat membandingkan DBI kandidat dan menandai eksperimen terpilih.
Training Backpropagation mengacu pada clustering run tertentu dan menyimpan konfigurasi serta metrik.
Data uji tidak digunakan untuk fit scaler atau pelatihan model.
Prediksi hanya bisa dijalankan dengan model berstatus ready.
Prediksi menggunakan preprocessing yang sama dengan model terkait.
Laporan menunjukkan identitas batch, run, dan versi model.
UI menjelaskan bahwa label cluster bukan keputusan resmi kelayakan beasiswa.
