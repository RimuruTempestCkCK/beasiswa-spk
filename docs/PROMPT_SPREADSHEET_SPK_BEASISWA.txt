STRUKTUR SHEET 2: "PREDIKSI_REKOMENDASI" (TEMPAT EKSEKUSI DATA BARU)
================================================================================
Sheet ini digunakan untuk memasukkan data pendaftar baru dan langsung menghitung rekomendasi kelayakan secara otomatis menggunakan rumus Excel/Spreadsheet.

Tata Letak Kolom:
[BAGIAN 1: INPUT DATA MAHASISWA BARU]
- Kolom A : No
- Kolom B : Nama Pendaftar
- Kolom C : IPK (contoh: 3.80)
- Kolom D : Penghasilan Ortu (contoh: 800000)
- Kolom E : Tanggungan (contoh: 5)
- Kolom F : Prestasi Akademik (contoh: 3)
- Kolom G : Prestasi Non-Akademik (contoh: 3)
- Kolom H : Kehadiran % (contoh: 95)

[BAGIAN 2: NORMALISASI FITUR MIN-MAX [0, 1] - RUMUS KODE SPK]
- Kolom I (IPK_norm)           : =(C2-2.2)/(3.95-2.2)
- Kolom J (Gaji_norm)          : =(D2-700000)/(8000000-700000)
- Kolom K (Tanggungan_norm)    : =(E2-0)/(6-0)
- Kolom L (PresAkad_norm)      : =(F2-0)/(4-0)
- Kolom M (PresNonAkad_norm)   : =(G2-0)/(4-0)
- Kolom N (Kehadiran_norm)     : =(H2-62)/(100-62)

[BAGIAN 3: JARAK EUCLIDEAN KE SENTROID KLASTER ACUAN]
- Kolom O (Jarak ke C0 - Tidak Layak):
  =SQRT((I2-0.1003)^2 + (J2-0.7641)^2 + (K2-0.1111)^2 + (L2-0)^2 + (M2-0)^2 + (N2-0.1053)^2)

- Kolom P (Jarak ke C1 - Layak Cadangan):
  =SQRT((I2-0.6848)^2 + (J2-0.1359)^2 + (K2-0.5513)^2 + (L2-0.5769)^2 + (M2-0.4423)^2 + (N2-0.6883)^2)

- Kolom Q (Jarak ke C2 - Sangat Layak):
  =SQRT((I2-0.9167)^2 + (J2-0.0236)^2 + (K2-0.8333)^2 + (L2-0.9167)^2 + (M2-0.8333)^2 + (N2-0.9112)^2)

- Kolom R (Jarak ke C3 - Dipertimbangkan):
  =SQRT((I2-0.3639)^2 + (J2-0.3831)^2 + (K2-0.2917)^2 + (L2-0.1406)^2 + (M2-0.1875)^2 + (N2-0.4005)^2)

[BAGIAN 4: KEPUTUSAN KLASTER & KELAYAKAN BEASISWA]
- Kolom S (Jarak Terdekat Minimum):
  =MIN(O2:R2)

- Kolom T (Klaster Hasil Prediksi):
  =IF(S2=O2, "C0", IF(S2=P2, "C1", IF(S2=Q2, "C2", "C3")))

- Kolom U (Status Rekomendasi Resmi):
  =IF(T2="C2", "SANGAT LAYAK (Prioritas Utama)", IF(T2="C1", "LAYAK (Kandidat Cadangan)", IF(T2="C3", "DIPERTIMBANGKAN", "TIDAK LAYAK")))

- Kolom V (Skor SPK / Ranking):
  =ROUND(IF(T2="C2", 95 - S2*10, IF(T2="C1", 80 - S2*10, IF(T2="C3", 65 - S2*10, 45 - S2*10))), 2)
